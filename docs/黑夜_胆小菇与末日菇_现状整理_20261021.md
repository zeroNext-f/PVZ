射击资源 `ScaredyShroom_shooting` 长1.16667动作秒，在0.666667处调用 `_shoot_bullet()`；射击分支TimeScale为2.0，外层基础TimeScale为1.0。因此在个体倍率1时，该分支名义时长约0.58333秒，发弹点约0.33333秒，另有OneShot淡入/淡出各0.3秒的混合配置。卡片冷却7.5秒与射击周期1.5秒是两套独立计时。

正常方向的孢子走二类防具→一类防具→本体的普通结算，不附带剧毒、冰冻、黄油、魅惑或大喷菇扩散。已有寒冰状态的目标会按共用生命组件受到1.5倍正伤害，即基础20通常结算为30，再按目标防具/抗性处理；读报第二生命可对普通来源减伤。

不能用“长射程”理解为可射击空中、地下、跳跃或潜水目标：本株射击检测状态为1，其他状态不满足；潜水僵尸露头为正常状态时才按该状态处理。已魅惑僵尸不在植物的敌方检测/受击碰撞层中，不作为常规射击目标。

### 害怕机制

| 项目 | 当前设置 |
| --- | --- |
| 组件 | ScaredyComponent，独立DetectComponent |
| 触发 | 近身范围内存在符合状态的敌方僵尸 |
| 是否限定同行 | **false，可检测邻行** |
| 范围形状 | 半径109、高378的胶囊，旋转约90度，成为横向胶囊 |
| 区域中心 | 植物根偏移(0,-25) |
| 几何外接尺寸 | 约**378×218像素**，水平±189、垂直±109；两端为圆弧，不能当完整矩形 |
| 检测状态位 | **31=正常1＋跳跃2＋水下4＋空中8＋地下16** |
| 不含状态 | 跳入泳池32；具体目标是否真的进入范围还取决于受击框当前可监测状态 |
| 实际敌方碰撞层 | DetectComponent就绪后设置为4；场景中该区域初始mask=0并非始终不检测 |
| 害怕时禁用组件 | **AttackComponent** |
| 是否无敌/减少伤害 | **否**，仍是正常可受击植物，300生命不变 |
| 害怕持续时间 | 无固定秒数，取决于范围内是否仍有合格敌人 |
| 恢复条件 | 范围内不再有合格敌人，解除Scaredy禁用因素 |

检测采用碰撞区域相交，不是到僵尸根节点的固定欧氏距离，所以不能把上述±189像素写成精确“根坐标小于189就害怕”。也不是写死的3×3格判定。体型不单独参与害怕筛选。

触发时 `is_scared=true`，切入缩头、瑟缩循环并停掉攻击计时器；离开、死亡或状态变化会请求重新检测，解除时只撤销害怕这一原因，休眠等其他禁用原因仍有效。友方魅惑僵尸不会触发此敌方检测。

**正在播放的射击有一个代码边界**：停攻会停止SpeedTimer，但 `set_cancel_attack()` 目前为空，`_shoot_bullet()` 本身也没有再次检查害怕/组件启用。因此已请求的射击OneShot可能继续到发弹关键帧，出现缩头后补出一发；不能据源码保证“开始害怕那一刻之后绝无子弹”。已飞出的孢子也不会因植物害怕而被清除。本次只记录，不改该行为。

### 动画、休眠及其他交互

- 常态/休眠循环各1.25动作秒，害怕循环0.833333秒，恢复伸出动作 `grow` 为0.75秒；这里的grow仅是伸出动画，没有阳光、生命或攻击成长机制。
- 缩头过渡资源 `ScaredyShroom_scared` 未显式覆盖Animation.length，使用引擎默认1秒；并非害怕只持续1秒。
- 状态树按害怕进入缩头再瑟缩，解除后进入伸出再回常态；部分过渡等待当前动作结束，因此动画形态与逻辑启停不是同一个计时器。
- 独立眨眼组件关闭。受击、啃食、铲除及死亡沿用普通植物流程，没有啃食附加效果或死亡攻击。
- 白天睡眠禁用眨眼、害怕组件和攻击组件；黑夜醒着无需咖啡豆。咖啡豆沿用0.5秒压缩、0.5秒伸展、0.5秒恢复后唤醒，共1.5游戏秒。

正常黑夜出战解除待机（`is_idle=false`）后进入 `DoomShroom_explode`，资源长度 **0.8动作秒**，末尾同时配置 `character_death()` 和 `bomb_once()`。不是先等待idle资源1.58333秒再额外等待0.8秒；idle主要供待机/展示，状态切换实际帧开销另计。

基础倍率1时名义约0.8秒引爆；0.9～1.1个体随机倍率下约 **0.727～0.889秒**。死亡亡语会先请求引爆，组件 `is_bomb` 标记防止末尾另一条事件重复伤害/造坑。不存在持续输出周期或第二次爆炸。

### 伤害结算与特殊目标

- **不是全屏炸弹，也不是固定“五行全部命中”**。不额外限制行号不等于不限制距离，354×352矩形与目标当前受击框相交才纳入。
- 每个符合条件的普通僵尸得到1800基础穿透伤害；二类防具与一类防具/本体按工程Penetration规则结算，不是直接强制清除。原生命和抗性可让目标存活。
- 寒冰减速或完全冻结目标的通用正伤害倍率为1.5，基础1800通常变2700，再参与目标自身抗性；冰冻与减速同时存在也只乘一次。
- 读报第一生命若被本次爆炸击穿本体或报纸，记录灰烬致死来源，进入破报反应及第二生命；第一生命致死溢出不继续灌入第二生命。已在第二生命且记录灰烬抗性时，本次基础1800按90%减伤通常为180；若带寒冰易伤则通常为270。
- 非土豆雷开关使中、大体型与小体型都使用1800基础值。空中气球、橄榄球顶飞等状态在63内，但仍需受击区域可监测并落入爆炸空间范围；不能保证所有空中单位均被命中。
- 已魅惑僵尸检测层32不在此掩码内，通常不被这次友方爆炸命中。两种植物都没有专门“炸魅惑僵尸”的逻辑。
- 普通僵尸被爆炸致死会禁用其亡语，清除及灰烬表现由原受击接口处理；部分特殊僵尸覆写该接口，如读报的第一生命切换。不能把所有死亡表现统一理解为灰烬动画。
- 僵王只在爆炸矩形覆盖有效受击区域且受击窗口开启时承伤；通过穿透子弹伤害接口，不走普通僵尸的直接删除链。并非像寒冰菇/辣椒一样直接遍历全场僵王。
- 范围内可查询到的梯子按现有流程销毁，同一梯子去重处理；没有主动清除墓碑、冰道、珊瑚或博士火球的专属全场事件。

### 坑洞

引爆成功后发出一次 `signal_bomb_once`，末日菇将该信号连接到所在格的 `create_crater()`。伤害结算完毕后造坑，**没有命中僵尸也会造坑**。

| 项目 | 当前实现 |
| --- | --- |
| 坑洞位置/数量 | 本株所在格，一个 |
| 总存续时间 | **180游戏秒** |
| 前半段 | 0～90秒显示完整坑洞 |
| 后半段 | 90～180秒显示消退坑洞 |
| 暂停 | 两段Timer均不累计场景树暂停时间；仍服从全局游戏倍速 |
| 黑夜贴图 | 前院黑夜组索引1 |
| 禁种 | 先设置IsCrater，普通植物种植判定被阻止 |
| 同格植物 | 清空普通、壳、悬浮、模仿者、底层，底层最后处理；不触发连带亡语 |
| 已死亡自身 | 不重复处理，末日菇按原死亡流程释放 |
| 结束 | 清除IsCrater标记，释放坑洞，其他仍在的禁种原因继续有效 |

造坑导致同格南瓜、睡莲、花盆等一并清除，是独立的同格清理，并非1800伤害扩大到友方植物。其他格子的植物不会因该清理被删除。坑洞不会自行对经过的僵尸造成伤害。

该入口是陆地黑夜；跨入口的共用坑洞仍会按格子原始地形及背景选择陆地、水池、屋顶平面或斜面贴图，不被睡莲/花盆临时改变的种植条件误导。

### 休眠、提前死亡与铲除

- 白天睡觉时禁用BombComponent，播放2秒循环睡眠动画，正常不会自动爆炸；黑夜不睡觉。咖啡豆1.5秒唤醒结束后再进入引爆流程。
- 醒着、爆炸组件启用、尚未发动且允许亡语时，正常提前死亡会立即引爆并造坑，例如允许亡语的普通啃食致死。不是必须等0.8动作秒。
- 铲除先设置 `is_can_death_language=false`，所以未引爆就被铲掉时**不爆炸、不造坑**。其他移除方式是否引爆取决于是否禁止亡语，不能概括成“任何死亡都爆炸”。
- 睡眠中死亡因为爆炸组件禁用，不会引爆或造坑。坑洞同格清理也明确禁止连带亡语，不产生同格多炸弹连锁。
- 普通idle资源1.58333秒循环，引爆动作0.8秒非循环，睡眠2秒循环；爆炸蘑菇云特效独立idle资源约1.00001秒，播完释放，不是额外的引爆等待。
