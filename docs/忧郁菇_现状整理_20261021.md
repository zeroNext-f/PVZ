## 升级与种植

1. 映射 `AllPrePlantPurple` 明确要求大喷菇，不能在空地直接种忧郁菇，也不能覆盖普通蘑菇或已有忧郁菇。
2. 紫卡可用性先检查场上是否有匹配前置，手持时对匹配大喷菇显示明暗提示；落点按该格前置植物判断，不按空地普通种植分支判断。
3. 成功升级时清除该格的大喷菇，再新建忧郁菇；**不是给原大喷菇原地换脚本**。新实例生命为300，不继承大喷菇残血、动作进度或休眠状态。
4. 同格的壳和底座不因这一普通紫卡升级流程一并删除；忧郁菇仍占普通层。前置在睡莲/花盆上时沿用该格底座与坡面位置修正。
5. 大喷菇当前已改为第一次喷射后死亡，故正常对局通常需要在它首发消失前完成升级；不能将已经消失的大喷菇视为仍可升级的前置。
6. 当前大喷菇基础价75，场上尚无忧郁菇时，普通卡正常先种大喷菇再升级的合计阳光为 **75＋150=225**；底座等额外费用另计。
7. 普通紫卡条件只通过前置分支取得匹配大喷菇，不额外加入本株专属地形检查；本次不修改现有判定。

当前全局已有植物列表包含43。是否展示该卡仍遵守当前关卡的候选/解锁列表；本次不改变可选范围和解锁。

## 攻击方式与范围

忧郁菇不是向八个方向发射八颗可飞行的子弹。它由攻击动画调用根脚本 `attack_once()`，每次先播放一组周身喷雾粒子，然后重新查询范围内所有合格敌人，对每个敌人直接调用：

`be_attacked_bullet(20, BulletRegistry.AttackMode.Penetration)`

| 项目 | 当前配置 |
| --- | --- |
| 调度组件 | AttackComponentBulletBase，复用攻击计时器及OneShot请求 |
| 基础攻击调度周期 | **2.0秒** |
| 首次启动等待 | 随机0～2/3动作秒，最少0.001，再等待攻击动画关键帧 |
| 每轮伤害脉冲 | **4次** |
| 每次基础伤害 | **20**，每个合格目标独立承伤 |
| 完整一轮单目标基础伤害 | **80**，前提为4次脉冲都在范围且可受击 |
| 名义持续单目标基础DPS | **40**，80÷2；为调度配置换算，不是局内计时测量 |
| 基础伤害模式 | **Penetration穿透** |
| 是否按同行限制 | **false**，可攻击邻行 |
| 实际检测形状 | **238×204像素矩形** |
| 范围中心 | 区域偏移(0,-25)＋形状偏移(0,-2)，合计植物根局部(0,-27) |
| 几何覆盖 | x=-119～119，y=-129～75；以目标受击框相交判断 |
| 检测碰撞层 | mask=4，植物阵营的敌方僵尸检测框 |
| 可攻击僵尸状态 | 默认 **1，正常** |
| 同一脉冲去重 | 按角色引用去重，一个目标多个受击框不重复扣血 |
| 一次命中目标总数 | 脚本未设数量上限，当前范围内所有合格目标 |
| 子弹飞行速度/射程 | 不适用，本伤害链没有创建飞行子弹 |
| 攻击后消失 | 不会，可反复进入攻击轮次 |

范围是周身矩形，不是严格圆形或写死3×3格；根坐标之外还要考虑目标受击框大小、所在行高度及坡面修正。它可以打到身后和上下方向，不需要转向追踪。

场景虽填写 `attack_bullet_type=4`（大喷孢子），但动画没有调用 `_shoot_bullet()`，也没有配置子弹发射标记。本株的实际伤害来自自身 `attack_once()`，因此**不继承大喷菇450像素飞行射程、扩散异常状态或喷一次后死亡**。八方向喷雾是表现，单次20不会因为有八组粒子就变成160。

## 动画与四连发节奏

攻击资源 `GloomShroom_shooting.tres` 长 **2.25动作秒**，非循环。四个根方法调用时刻如下：

| 脉冲 | 动画内时刻（秒） | 距上一次间隔（秒） |
| --- | --- | --- |
| 1 | 0.666667 | 从片段开始等待0.666667 |
| 2 | 1.000000 | 0.333333 |
| 3 | 1.342110 | 0.342110 |
| 4 | 1.666670 | 0.324560 |

这四次都执行完整的范围重查，不在轮次开始时锁定一组敌人。因此进入范围较晚的僵尸可以只吃到后几次，提前离开的僵尸也可以避开剩余脉冲。

基础调度2秒与资源长度2.25秒是不同配置，不能把2.25秒写成攻击冷却；连续请求的实际动画衔接受OneShot处理影响，本文未作局内计时验收。OneShot淡入/淡出各0.2秒，常态与睡眠之间状态切换混合各0.2秒。

个体随机0.9～1.1同时影响调度及外层动画，通常调度周期约 **1.818～2.222秒**；按完整四次全命中换算的基础DPS约 **36～44**。首次随机等待不是首伤时刻，后面还要推进到首个0.666667动画事件。

常态和睡眠资源各1.5秒循环，另有0.333333秒的眨眼资源、5.416667秒的face资源；主场景动画库挂载idle、shooting、sleep。四组 `Bullet_FX` 循环使用，每组八个单次GPUParticles2D，共32个粒子节点；每节点amount=5、lifetime=0.4秒，随机amount_ratio为0.6/0.8/1.0。这些随机值仅影响喷雾粒子数量，不改变20点伤害、四脉冲或判定范围。

场景填写 `attack_sfx=Fume`，但本株四次回调没有调用共用的 `play_throw_sfx()`，攻击动画也只调用 `attack_once()`；因此不能只凭这个字段认定当前四脉冲一定播放Fume音效。目标的通用受击音效仍可能由伤害接口播放。

## 伤害与特殊交互

- Penetration在本工程不是“直接扣本体且忽略所有防具”：会同时对二类防具扣本次伤害，并让同额伤害继续走一类防具→本体。一类防具不足时只把该部分溢出传给本体。
- 普通铁门不能完全挡住周身穿透伤害；被传播路障/铁桶的铁门仍可由新增一类防具承接本体侧伤害。它不是磁力移除铁门的效果。
- 普通来源可被读报第二生命对应的90%抗性减伤：无其他倍率时每次20→2，一轮完整四次通常8。不会按灰烬或碾压来源计算。
- 寒冰减速或完全冻结目标受到共用1.5倍正伤害：每次20通常变30，四次全中120，再走目标防具/抗性；减速与冻结同时存在仍只乘一次1.5。
- 本株没有剧毒、冻结、减速、黄油、魅惑或烧灼附加，也没有大喷菇的状态扩散。升级不会从原大喷菇继承弹丸脚本。
- 状态1筛选意味着不攻击当前处于跳跃、水下、空中、地下或跳入泳池等其他状态的僵尸。潜水僵尸露头变正常状态后可按状态攻击；顶飞中的僵尸按空中状态筛除。
- 已魅惑僵尸不在植物敌方检测层4内，通常不被纳入攻击，也不会因其站在范围内启动攻击。体型本身不是本株的伤害分支条件。
- 僵王按范围内受击区域和受击窗口决定是否成为有效目标；伤害使用角色通用穿透接口，不全场命中，也不按普通僵尸删除链清除僵王。
- 停攻会停止SpeedTimer，但共用 `set_cancel_attack()` 目前为空，忧郁菇 `attack_once()` 也没有额外检查攻击组件启用状态。因此已启动的OneShot不保证立即终止，后续事件仍可能执行范围重查；正常无目标时这些重查为空。本次仅记录该边界，不修改实现。

## 休眠、受伤和移除

当前场景直接继承 `plant_000_base.tscn`，**没有设置 `is_sleep_in_day=true`**，所以现行默认下白天也不会自动睡觉，升级时也没有将前置大喷菇的休眠状态转移给新实例。不能直接套用原版“忧郁菇白天必睡”的规则。

场景保留睡眠动画和基础SleepComponent，但其睡眠影响列表只继承眨眼组件，没有把AttackComponent加入睡眠禁用列表；这与“自动休眠关闭”分别是两个配置现状。若后续要改为白天休眠，不能只改动画或单一布尔值而忽略攻击组件关联。

本株没有胆小菇害怕模块、啃食附加效果、死亡攻击、爆炸或坑洞。啃食、碾压、铲除、被偷等沿用普通植物对应入口；铲除不刷新卡片冷却。血量下降不降低其伤害或攻击速度，死亡后按普通植物逻辑释放实例。
