### 种植条件

1. 格子必须存在有效墓碑。
2. 普通植物层必须为空，不能重复种在正在工作的另一株墓碑吞噬者上。
3. 特殊种植判断直接检查上述条件，不走普通植物的“无墓碑可种植格”条件，因此可以种到原本被墓碑占用的格子。
4. 资源的地形位掩码是 63，但不能理解成任意空地都能种：实际入口走特殊判断，仍必须有墓碑。当前黑夜是陆地场景。

### 工作过程与具体时间

| 时点（动画原始时间） | 当前行为 |
| --- | --- |
| 正常出战初始化 | ready_norm 调用 `_start_eat_grave()`，播放 GraveBusterChomp |
| 动作 0 秒 | ALL_ANIMS 方法轨道也配置 `_start_eat_grave()` |
| 每次开始调用后 0.5 游戏秒 | 开启吞噬粒子；墓碑遮罩 y+30、墓碑精灵 y-30，表现被吞入 |
| 动作 3.08333 秒 | `_end_eat_grave()`：标记完成、将粒子移到格子、停止继续发射、删除墓碑 |
| 动作 3.16667 秒 | 调用自身 `character_death()`，清理植物及占位 |
| 完成后的粒子 | 保留已有粒子，独立等待 2 秒后删除 |

实际完成时间随动作随机倍率 r 变化：墓碑约在 3.08333/r 秒删除，即约 2.803～3.426 秒；植物约在 3.16667/r 秒消失，即约 2.879～3.519 秒。0.5 秒的开始等待和粒子的 2 秒回收使用普通计时器，不按该个体动作倍率缩放。

成功只删除当前格子的这一座墓碑，不是范围吞噬、不按墓碑生命扣血。墓碑从格子与管理器列表移除，数量减一；下一帧解除格子的墓碑禁种标记。墓碑消失后不再作为这座墓碑的后续出怪来源；已经生成的僵尸不随之被清除。没有额外阳光、金币或卡片冷却刷新奖励。

### 被打断、铲除与现存实现细节

- 吞噬完成前被啃死或铲除：沿植物死亡流程删除自身；未完成标记下调用 `failure_eat_tombstone()`，恢复墓碑遮罩，墓碑保留，可再次使用墓碑吞噬者处理。
- 吞噬完成后再进入死亡流程，不执行墓碑失败恢复。
- 铲除沿用共用铲子规则，不退还阳光、不刷新卡片冷却。
- 正常出战播放一次 ALL_ANIMS；展示使用循环 Gravebuster_idle（原始长 2.25 秒），不使用正常出战吞噬流程。另有原始 Gravebuster_land 资源（0.5 秒），现行场景使用的是内嵌完整动作，不能在 3.16667 秒外再加一个落地段。
- **现存代码有两个开始入口**：ready_norm 和动画 0 秒事件都调用开始方法，而方法没有防重标记。静态上存在重复音效、重复等待及墓碑遮罩偏移累加的可能；失败恢复也固定回退 30。此处仅记录，未擅自修复，未用运行结果确认调用次数。

### 生命分段与防具

| 条件 | 当前变化 |
| --- | --- |
| 头盔剩余 ≤932 | 第一阶段破损，换 helmet2 贴图 |
| 头盔剩余 ≤465 | 第二阶段破损，换 helmet3 贴图 |
| 头盔剩余 =0 | 头盔脱落，取消铁器身份；本体继续存活与啃食 |
| 本体剩余 ≤179 | 掉手，替换右上臂，隐藏右前臂及手掌并生成掉落物 |
| 本体剩余 ≤89 | 掉头并进入逻辑死亡；关闭攻击与受击，执行原死亡动画 |
| 本体绕过防具致死 | 先检查并清除剩余一类头盔，再走掉头/死亡，已有脱落不重复生成 |

阈值来自共用公式：本体 `max_hp*2/3-1`、`max_hp/3-1`；防具同公式并增加 0 阶段。1400 防具的整数阈值为 932/465/0，**不是 933/466**。

纯普通伤害从满血开始，先打完 1400 头盔，再使本体从 270 降至 89，即累计 1581 点即可触发逻辑死亡。若每次固定 20、没有其他修正，需要 80 次命中；这是数值推导，不是局内实测。逻辑死亡后残留本体生命由共用组件每 4 个物理帧继续流失，死亡表现不等待本体再被打到 0。

普通、穿透、Real 模式在该角色没有二类防具时，均先消耗一类头盔，溢出扣本体。项目里的 Real 名称不表示能绕过一类头盔；IgnoreArmor1 才能直接绕过头盔。剧毒也直接扣本体。普通伤害没有额外减伤系数。

### 攻击

- 当前攻击方式为**普通持续啃食**，不是碾压或冲撞。选中合格目标后停下移动，播放原啃食动画；目标不再有效时重新索敌并恢复行走。
- 基础伤害参数为 **100/秒**。变量虽名为 `init_attack_value_per_min`，实际公式按每秒使用。
- 当前攻击值 `int(100 × 各速度影响因素乘积)`，无控制/场外因素时随个体随机约为 90～110。动画自身的基础 2.0 **不再乘入啃食伤害**，因此不能理解成默认 200/秒。
- 每 8 个物理帧扣一次：`int(当前每秒攻击值 × delta × 8)`。例如稳定 60 物理帧/秒、倍率为 1 时，每次 13 点、约每 0.1333 秒一次，长期约 97.5/秒；整数截断与帧率会使实际值略低于参数值。冻结、黄油倍率为 0 时该扣血量为 0。
- `attack_once` 动画事件主要负责目标闪光、特殊被咬回调与 Chomp 音效，并非一次固定 100 点。原啃食动画长 2.91667 秒，事件在原始 0.833333、2.25 秒；r=1 时循环约 1.4583 秒、事件约在 0.4167、1.125 秒。
- 同行近距离检测框：50×5，中心 (-13,-40)；可咬正常、低矮植物（状态掩码 9），不按普通啃食吃地刺/悬浮植物。格子内沿共用层级选择保护层目标。
- 普通阵营可咬植物与魅惑僵尸；被魅惑后反向行走、改检测敌对僵尸。脑子是其他模式的共用道具攻击，每次动画事件 25 点，黑夜正常战斗不涉及脑子。

- 真实受击与检测框继承胶囊：半径20、高100、中心(0,-50)；攻击时受击横向修正 -20。
