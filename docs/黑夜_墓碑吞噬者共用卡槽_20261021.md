# 墓碑吞噬者：双卡共用槽位

## 选卡规则

- 选中墓碑吞噬者后，下一张成功新选中的可出战卡进入它的下层；两张卡只占一个物理槽位。
- 选卡画面仍显示墓碑吞噬者的卡面。配对完成后，后续新卡正常占用其他槽位；每组只有两张，不无限嵌套。
- 即使物理槽位已满，只要墓碑吞噬者的下层尚空，仍能补选一张卡。未配对也允许开始对局，届时它是普通单卡槽。
- 普通墓碑卡与模仿墓碑卡按各自的选卡身份处理；下层也可以是模仿卡，仍保留原有模仿者只能选择一张的限制。
- 原候选页、解锁和可选范围不变，不会因此解锁额外角色。只在普通选卡/重选流程建立组合，不重写传送带或金币卡槽规则。

## 单独取消（按用户后续补充）

| 点击位置/对象 | 结果 |
| --- | --- |
| 选卡槽中的已配对墓碑吞噬者 | 只取消墓碑吞噬者；原下层卡提升为独立可见卡，继续占用同一个槽位，不释放槽位 |
| 角色池中的已选墓碑吞噬者 | 同上，只取消它自己 |
| 角色池中的已选下层卡 | 只取消下层卡，墓碑吞噬者继续占原槽位，等待下一次成功新选卡 |
| 单独占槽的卡 | 取消自己并释放该槽位，后续槽位依次前移 |
| 全部取消 | 逐张独立取消所有玩家已选卡，包括隐藏下层，不留下晋升后漏掉的卡 |

系统配置的锁定预选卡仍不可取消。角色池原位置保留卡面，左键可对已经移入槽位的对应卡发送取消操作；未选卡仍由正常卡片按钮处理。

取消墓碑后没有把其槽位资源归还为空位，也没有把仍保留的下层卡送回角色池。取消一张卡不修改另一张卡的身份、费用或冷却配置。

## 对局切换与使用

- 每次进入战斗默认显示墓碑吞噬者，下层隐藏且禁用。
- **在共用卡槽卡面上右键**交换上下层：下层变上层并显示自己的卡面、费用、冷却遮罩和快捷键；墓碑卡隐藏并禁用。再次右键切回，可无限循环。
- 切换不要求两张卡已冷却或阳光足够；切换后的上层仍按自身费用、剩余冷却、种植条件等判断能否使用。
- 两层都是独立Card实例，隐藏不停止_process；已经启动的冷却无论在上层还是下层均正常推进。切换不重置、不暂停、不共享、不额外开始冷却。
- 使用某一层时仅按该层的费用扣一次阳光，并仅启动该层自己的冷却。墓碑吞噬者保持50阳光、7.5秒冷却，下层使用其现行配置。
- 阳光变化和紫卡动态费用对上下层分别更新，隐藏卡不会使用墓碑卡的价格。
- 数字快捷键按物理槽位编号，始终选择当前上层，不允许绕过下层禁用。
- 右键切换兼容原来的取消手持操作：先撤销正在手持的卡牌/工具和预览，再切层，避免继续种下刚被禁用的旧层。

## 重选、预选与保存

- 选卡保存同时写入两张实际卡的引用，在墓碑根卡添加“与下一张共槽”标记；不增加其他内容的身份类别，不保存费用和冷却运行状态。
- “上次选卡”按明确关系恢复，避免取消下层后留下的未配对墓碑卡误吞后一个独立槽位。取消墓碑后晋升的普通卡按独立槽位保存。
- 不含新标记的旧三字段选卡引用继续可读，按原有独立槽位恢复。
- 普通多轮重选仍沿用既有清空冷却策略，并恢复墓碑卡面；两张卡均保留在同一槽。系统预选按顺序建立组合，原锁定资格不改变。
- 选卡移动补间按卡片替换，快速取消、重新选择和槽位前移不会由旧回调移回旧位置。

## 实现位置

- `scripts/ui/card/card.gd`：两层关系、禁用资格、独立冷却、右键切换及快捷键转交。
- `scripts/ui/card/card_slot/card_slot_norm/card_slot_norm.gd`：下一张新选卡配对、按物理容量计数、分别取消、下层晋升、选卡保存恢复。
- `scripts/ui/card/card_slot/card_slot_norm/card_slot_battle.gd`：展开实际卡片处理阳光、战斗上下文、成功结算及紫卡价格。
- `scripts/ui/card/card_candidate_container.gd`：角色池中已选卡原位的独立取消入口。
- `scripts/resources/card/card_reference.gd`：兼容原格式的可选共槽关系标记，不参与模板键或选择键。
- `scripts/manager/card_manager.gd`：原调试零冷却覆盖同时处理两层，不修改正常对局冷却。
