# 橄榄球僵尸：冲刺、整格顶飞、撞植物后的慢走与啃食

> 2026-10-22动画兼容修复：原版啃食、死亡、待机、行走文件保留，场景改用 `008_zombie_football/compatible/` 中仅统一旋转插值的独立副本，解决与新冲撞动作混合时重复输出警告。帧数据、时长、贴图及战斗机制不变，详见《调试器108条警告修复_20261022.md》。

## 已实现的阶段

1. 正常出战入场播放已制作的加速奔跑循环，实际移速为旧橄榄球常规移速的2倍；整个冲刺及前扑收势期间禁用普通啃食组件，不播放啃食动作，也不结算啃食伤害。
2. 未魅惑时首次接触其他僵尸，按其所在道路与格子选出同格所有存活僵尸（普通、魅惑实例均包含，排除橄榄球自己），沿橄榄球当前行进方向顶飞三格。每只橄榄球只触发一次整格顶飞。
3. 按用户确认，顶飞后不结束冲刺；继续奔跑至首株植物。
4. 接触植物时锁定该株，停步播放前扑、撞击定格和收势。在前扑完成的关键帧对该株结算一次6000点Penetration穿透伤害。目标已被移除则落空，不转伤后补植物。
5. 收势结束后播放已确认的0.5倍慢走循环，遇可啃食目标恢复项目原版啃食动作；离开攻击恢复慢走。实际行走速度取通常普通僵尸的常规速度，与慢走动画节奏独立。
6. 角色设为中体型Medium。原270本体、1400头盔、179/89本体阈值等未指定数值保持原配置；死亡取消未结算撞击并立即停步，接原版死亡动作。
7. 奔跑期间被魅惑后反向冲刺，不再顶飞任何僵尸、也不撞友方植物。仅锁定首个碰到的敌方僵尸，播放同一前扑、定格和收势，对该单体造成1800点普通来源的Penetration穿透伤害，然后进入上述慢走及啃食流程。此前是否已使用过整格顶飞不影响这次魅惑撞击。

## 数值与判定

| 项目 | 设置 |
| --- | --- |
| 原橄榄球基准平均移速 | 约24.82755像素/游戏秒，由原30像素地面轨道、2.41667秒长度及基础2倍动作计算 |
| 入场冲刺基准移速 | 约49.65510像素/游戏秒，原速2倍 |
| 撞植物后的基准移速 | 约15.58957像素/游戏秒，由普通僵尸49.8像素/3.833333秒、基础1.2倍换算；两个普通行走变体的该值一致 |
| 个体及异常速度因素 | 继续叠加随机、寒冰、冻结、黄油、场外等现有因素 |
| 顶飞距离 | 本路实际格距的3倍；场外也延伸同一网格，不把所有场外单位合并成边缘一格 |
| 顶飞时长/峰高 | 0.75游戏秒、18像素低抛物线；这两个补充实现值可后续再调 |
| 撞植物伤害 | 6000，一次，仅最初锁定的一株 |
| 魅惑冲刺撞僵尸伤害 | 1800基础伤害，一次，仅最初锁定的一只敌方僵尸；不伤同格其他僵尸、不顶飞 |
| 魅惑撞击伤害分类 | 普通来源＋Penetration防具结算；读报第二生命若记录普通来源则减伤90%，无其他倍率时结算180 |
| 前扑伤害时点 | 撞击片段开始后0.25个动作秒，冻结等会暂停关键帧推进 |
| 撞击、定格、收势总长 | 约1.16667动作秒 |
| 慢走循环 | 约2.16667动作秒，已经含0.5倍节奏，不再额外乘0.5 |

植物同格有保护层时优先锁定外层：壳→普通→模仿者→地刺层→底座，一次只伤该株，不是整格6000伤害。冲撞接触可包含地刺、底座，恢复后的普通啃食仍沿用原检测范围和状态限制。未魅惑阶段的整格顶飞不以阵营过滤；魅惑奔跑阶段改为只撞敌方僵尸单体，排除其他魅惑僵尸和所有植物。

魅惑单体撞击沿用0.25动作秒伤害关键帧、约1.16667动作秒收势、一次性去重及弱引用锁定。目标在关键帧前死亡、消失或被魅惑则落空，不换目标，也不把伤害转给同格其他僵尸；收势后照常慢走。1800是基础值，沿用现行寒冰易伤及目标抗性，不是强制扣血或碾压清除。撞击植物过程中才被魅惑时，也不会继续伤害已经同阵营的植物。

被魅惑的僵尸属于友方，魅惑奔跑橄榄球途经其他魅惑僵尸直接略过，不撞、不顶飞、不转慢走。离场前始终未接触敌方僵尸时保持冲刺，越过管理器既有右侧清理边界（当前世界横坐标1000）后调用正常直接清除入口，完成死亡登记、移出魅惑列表并释放实例。该检查独立于仅末波/无出怪模式运行的全局离场计时器，避免中间波次残留；不更改全局边界或其他僵尸清理规则。

## 临时空中逻辑

- 被顶飞者暂设`Zombie000Base.E_BeAttackStatusZombie.IsSky`，与气球使用同一分类，现有地面/防空攻击筛选直接复用。
- 顶飞期间暂停自主移动、攻击与动作推进，模型沿外力低弧线移动；影子保持贴地，屋顶按横坐标补偿坡面高度。顶飞本身不扣血、不改阵营、不改行号和体型。
- 落地只撤销本次顶飞自己的禁用因素，恢复此前/期间其他机制请求的受击状态；不解除原有冰、黄油或其他机制的禁用状态。原来就在空中的气球仍恢复空中状态。
- 飞行中新增的通用冻结请求转为气球式减速，不追加冻结伤害；三叶草可按空中单位将其吹走。既有剧毒仍按原独立计时结算。
- 同一单位被另一只橄榄球再次顶飞时从当前位置和高度续接；死亡、清理车或吹走会清理原轨迹，避免落地后复活攻击、双轨迹争抢或悬空残留。
