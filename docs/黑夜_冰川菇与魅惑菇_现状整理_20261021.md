## 入口与范围

冒险选关 `scenes/main/02AdventureChooesLevel.tscn` 的“黑夜”入口引用 `resources/level_date_resource/mode_adventure/adventure_02_night.tres`。当前为前院黑夜：背景/BGM编号1，`is_day=false`，`is_day_sun=false`，启用墓碑，初始墓碑5；自然僵尸种类为1/3/4/5/6/7/8/9。

该入口未配置专属植物卡池，两株均已在 `GlobalGameState.curr_plant` 中；卡片身份分别为13、15。本文不调整可选卡范围、植物卡片解锁顺序、关卡解锁顺序、场地、阳光产出节奏、首波等待、波间刷新条件、出怪选行或胜负条件。只新增资料与改动记录，不修改任何游戏配置、脚本或动画。

## 二、冰川菇：一次性全场寒冰技能

### 触发时间与生命周期

黑夜种下后直接进入 `IceShroom_idle` 启动动画。该资源长度1.33333秒，在1.33333动作秒处同时配置 `character_death` 和 `BombComponent.bomb_once` 方法事件。

正常情况下约 **1.33333秒后发动并消失**；个体随机动作倍率0.9～1.1使纯动作时长约 **1.212～1.481秒**，这不是卡片冷却。状态切换及帧边界可能产生小量额外延迟，未作局内计时验收。

角色死亡调用亡语 `judge_death_bomb()`，爆炸组件又有 `is_bomb` 防重复标记，因此动画末尾的两条事件不会使同一株发动两次。发动后角色释放，特效脱离植物挂到游戏特效容器继续播放。

| 技能字段 | 当前设置与实际用途 |
| --- | --- |
| 冻结时长 time_ice | **3秒** |
| 解冻后减速 time_decelerate | **5秒** |
| 完全冻结速度倍率 | **0**，停移动、攻击节奏和动作 |
| 寒冰减速速度倍率 | **0.5**，影响移动、动作及通用啃食输出 |
| 爆炸组件 bomb_value | **0**；不能据此认定完全无伤害 |
| 实际通用冻结附加伤害 | **20点，AttackMode.Real** |
| 作用范围 | 管理器中全部行的敌方普通僵尸；另逐只处理存活僵王 |
| 范围实现 | 广播 ice_all_zombie(3,5)，不是距离碰撞或射线 |
| 行参数 bomb_lane | 默认-1；实际寒冰实现直接广播全场 |
| is_cherry_bomb | false，不走灰烬爆炸逻辑 |
| is_auto_bomb_in_death | true |
| 爆炸音效 | Frozen |
| 特效 | 全屏Ice效果、SnowFlakes粒子、目标脚下冰块与寒冰染色 |

### 伤害、冻结与重复施加

1. 通用冻结接口先结算20点Real，再检查目标是否死亡或待释放；仍存活才施加冻结。新目标首次受击通常为20；若目标原本已减速或冻结，现行寒冰易伤会将该次基础20放大至30，然后再走目标自身抗性/防具规则。
2. **Real是工程枚举名称，并非“无视所有防具直接扣本体”**。普通僵尸的实现跳过二类防具，先扣一类防具，再将溢出传给本体。因此铁门不能单独挡住这次伤害，但传播取得的一类路障/铁桶可以承接；读报还会走其专用生命及抗性逻辑。
3. 冻结时长采用“当前剩余时间与新时长取较长”的逻辑，不相加。剩余超过3秒不会被缩短，不足3秒时延至本次起算3秒；重复施加仍会再次调用20点基础伤害。
4. 重复冻结时，解冻后的减速尾效取现存与新传入值的较大者；完全冻结结束后再开始5秒减速。已有减速计时独立运行，新减速也只延长、不缩短。单次标准效果为3秒冻结＋5秒减速。
5. 冻结/减速期间，通用正伤害存在 **1.5倍寒冰易伤**，两种寒冰状态同时存在仍只乘一次。剧毒走独立本体扣血通道，不因此自动乘1.5。
6. 寒冰可以与黄油、剧毒等独立状态并存；该技能不清除或复制这些状态，也不施加魅惑。冻结使动作倍率为0不等于停止剧毒独立计时。
7. 火焰类来源调用 `cancel_ice()` 时可解除冻结及减速，以对应来源的现行调用为准。

### 范围与特殊目标边界

- 管理器直接遍历 `all_zombies_2d`，寒冰组件自身不按距离、行号、体型、视野或攻击状态位筛选。即使组件默认 `can_attack_zombie_status=1`，该字段也没有参与这条全场实现，不能据此写成“仅地面正常僵尸”。
- 已魅惑僵尸会从敌方二维列表移出，因此后续本全场事件不会遍历它们。魅惑之前已获得的寒冰状态不会因为魅惑而自动清除。
- 气球僵尸覆写冻结接口：**转为3+5=8秒、0.5倍减速，不完全冻结、不扣通用20点伤害**。
- 橄榄球顶飞过程中的僵尸也由基础僵尸接口转为8秒减速，不完全冻结、不追加20点；这条边界源于现行顶飞机制。
- 小/中/大体型不是冰川菇通用冻结的分支条件；不要混同“寒冰豌豆按体型分配冻结/减速”的规则。当前黑夜的中体型橄榄球、舞王并没有因此免疫冰川菇。
- 读报第一生命在破报过渡阶段拒绝普通伤害；第二生命会按第一生命记录的伤害类别结算90%同类抗性。冰川菇的Real防具模式并不另创伤害来源类别，默认按普通来源处理。
- 所有存活僵王均收到调用，但各自的出战状态和受击窗口仍可拒绝；不能保证未开放受击窗口的博士被冻住。
- 同一事件还用于消除博士火球，直接消除，不对火球施加3秒冻结或5秒减速。
- 管理器另设置 `is_ice=true` 并计时3秒，用于珊瑚出怪抑制；这是既有旁路行为，本黑夜无水路，本文不调整其规则。

### 休眠、提前死亡与铲除

白天进入睡眠时禁用眨眼和爆炸组件；睡眠动画不自爆。咖啡豆通用唤醒表现为0.5秒压缩、0.5秒拉伸、0.5秒恢复，共1.5秒，然后解除睡眠；醒后再走启动动画。这些是跨入口共用行为，黑夜无需咖啡豆。

在爆炸组件启用且尚未发动时，若正常死亡并允许亡语，会提前发动全场效果；**铲除会先禁用亡语，不会发动**。睡眠中死亡因爆炸组件被禁用，也不会发动。其他清除来源是否引爆取决于它有没有关闭亡语，不能笼统写成“任意移除必爆”。

展示/图鉴使用 `IceShroom_idle_only`，不含启动末尾的死亡与技能事件；睡眠用 `IceShroom_sleep`，均为1.33333秒循环。正常启动资源也带循环标记，但正常生命周期会在第一轮末尾结束。眨眼默认间隔5秒，首次附加-1～1秒随机，属于共用表现。

## 三、魅惑菇：啃食事件转换阵营

### 实际触发条件

核心调用链为：僵尸啃食动画的 `attack_once()` → 目标植物 `be_zombie_eat_once(攻击僵尸)` → 魅惑菇 `_be_zombie_eat_once_special()` → `hypno_zombie()`。

**条件是尚存活且未睡眠的魅惑菇被触发一次啃食动画回调，不是必须300血被吃完，也不是任意一次接触或扣血。** 普通啃食的连续扣血和动画“咬一口”事件是两条路径；魅惑只挂在后一条。

| 项目 | 当前实现 |
| --- | --- |
| 对象 | 本次调用啃食回调的那一只 Zombie000Base |
| 数量/范围 | 单体；无范围传播、无远程索敌 |
| 触发次数 | 通常一次；触发后魅惑菇直接死亡释放 |
| 魅惑持续时间 | 无到期计时，持续到目标死亡或离场 |
| 几率 | 无概率判定，满足回调及醒着条件即调用 |
| 体型判断 | 无；入口中没有小/中/大体型限制 |
| 伤害、回血 | 本技能不扣目标生命、不回血、不修复防具 |
| 速度/攻击加成 | 无统一附加倍率；保留目标现有行为和速度因素 |
| 音效 | MindControlled |
| 颜色 | 身体附加Color(1,0.5,1)魅惑染色 |
| 本体方向 | 设置direction_x_root=-1，根节点水平翻转 |

### 转换后的行为与管理

- `is_hypno=true`，发出被魅惑信号；原来的血量、防具、剧毒、冻结、减速等不会在通用魅惑接口中重置。
- 受击检测层改为32，真实受击层改为1024；植物常规子弹的敌方碰撞配置因而不再把它当作原敌方僵尸。
- 攻击检测改为“植物阵营的敌人”配置并重启检测，转而攻击敌方僵尸；通用移动收到行走启动通知。具体攻击状态/范围和专属技能仍由该僵尸自身决定。
- 僵尸管理器将其从敌方该行列表移出，加入魅惑列表，敌方计数减1，移除其自然刷新登记，并断开原波掉血监听；调用现有波完成检查。这里描述的是既有魅惑效果，不改波间刷新或胜利条件。
- 全场冰川菇后续不再遍历这个目标；大喷菇扩散机制仍可能读取/传播魅惑，服从当前魅惑高于其他状态的既有优先级，不由魅惑菇额外实现。
- 舞王有专用魅惑覆写：切换舞蹈管理关系并建立带魅惑标记的管理器；其后召唤可沿用魅惑阵营。伴舞后续普通僵尸召唤也会按伴舞自身 `is_hypno` 转换新召唤者；不等于魅惑菇当场群体魅惑全部现存伴舞。

### 无法触发与特殊僵尸

- 睡眠中咬到不会施加魅惑，也不会因此自消失；仍能受到普通啃食伤害。
- 铲除、普通扣血致死、碾压、巨人砸击、被偷走或其他没有调用啃食一次回调的清除，不触发魅惑。该植物没有“死亡时魅惑凶手”的亡语。
- 当前橄榄球冲刺及前扑期间禁用啃食，碰到魅惑菇走6000穿透撞击，不会因这一撞击被魅惑；转入慢走并恢复普通啃食后，才可能触发魅惑菇。
- 当前读报第二生命用碾压，不会以碾压触发魅惑；第一生命普通啃食路径可以触发。
- 并非所有僵尸都能够正常啃食这株植物；无啃食路径者不能仅凭“无体型限制”理解为必可被这株植物直接魅惑。
- 若魅惑菇在“咬一口”事件到来前已经被其他伤害清除，也不会预存一次死亡后的魅惑机会。

### 动画与休眠

黑夜不休眠，常驻 `HypnoShroom_idle`，1.58333秒循环；白天为 `HypnoShroom_sleep`，同为1.58333秒循环。基础动作倍率1.0、个体随机倍率0.9～1.1；没有攻击动画或定时施法事件。场景关闭独立眨眼组件。咖啡豆沿用1.5秒唤醒过程，醒后即可响应啃食回调。
