# 冰川菇：落地释放、留场与点击引爆

> 后续更新：冰川菇与另外五株指定蘑菇已移除睡眠组件，白天不再休眠，因此下文关于白天睡眠阻止点击及咖啡豆唤醒的描述只作历史说明。爆炸组件其他禁用原因仍可阻止点击，见《六株蘑菇移除睡眠组件_20261022.md》。

按用户确认的两次释放方案实现。

- 正常新种植时立即释放一次全场冰冻，不检查BombComponent.is_enabling，不消耗组件is_bomb标记，不令植物死亡。白天休眠或组件默认禁用也不阻止这一次。
- 删除当前场景对原启动动画的引用，正常出战idle改用无方法事件的IceShroom_idle_only循环。原动画文件保留，但不会在1.33333秒后自动引爆或死亡。
- 首次释放后留场。正式对局空手左键点击该株所在格，且爆炸组件启用、未最终引爆、植物仍存活时，释放第二次全场冰冻并消失。
- 组件未启用（例如白天休眠）时点击无效，不消耗植物、不释放技能；咖啡豆按原流程唤醒并启用组件后可再点击。手持卡牌、铲子或手套不走空手激活入口；有罐子的格子保留原优先开罐行为。
- 原亡语规则保留：允许亡语且组件启用时，其他正常死亡仍可消耗剩余最终引爆；点击成功后is_bomb已置true，死亡亡语不会重复释放。铲除等禁止亡语的清除及组件禁用时死亡不补发。
- 两次均复用原3秒完全冻结＋5秒减速、原通用20点Real基础伤害及特殊目标接口；未调整范围、状态优先级、气球/顶飞处理或寒冰易伤。
- 首次特效复制原特效单独播放，原特效保留给最终引爆，避免第一次结束后第二次引用已释放对象。
- 展示和花园不触发落地技能；存档恢复的旧植物不重复触发。使用本格的同步恢复标记区分新种植，读档后的正常新种植不受影响。
- 费用75、卡片冷却50秒、本体300及白天休眠等未指定参数不变。
