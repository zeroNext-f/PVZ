# 六株蘑菇移除睡眠组件

范围：阳光菇、胆小菇、小喷菇、末日菇、冰川菇、大喷菇，编号10、14、9、16、15、11。

- 新增不含SleepComponent、zzz和AnimSleep子树的植物基础场景plant_000_awake_base.tscn，六株改为继承该场景；原基础场景及其他植物不变。
- 六株自己的睡眠节点覆盖、睡眠影响列表和方向补偿节点引用一并移除，is_sleep_in_day=false。保留既有动画素材文件，但正常流程不会进入睡眠状态。
- 植物共用脚本将睡眠组件设为可选，正常出战、花园、咖啡豆唤醒和存档恢复均先检查有效性，避免节点不存在时空引用。没有睡眠组件的植物读旧存档也保持醒着。
- 白天和黑夜均正常使用现有机制。冰川菇落地释放不变，留场点击不再因白天睡眠而被禁用；其他组件禁用原因仍可阻止点击。末日菇白天也按既有引爆流程发动，阳光菇仍落地产150阳光后死亡。
- 胆小菇缩头属于害怕状态，不是睡眠，本次保留；其无攻击动画四连发和轮末剧毒判定也保留。小喷菇无主动攻击和啃食亡语、大喷菇一次发射及扩散等均不改。
- 费用、冷却、生命、伤害和范围不变；其他蘑菇的睡眠组件不移除。

静态查询六场景及新基础场景均无SleepComponent引用、无缺失外部资源。Godot4.7.2编辑器加载及关联脚本检查退出码0，日志无错误或警告；未新增或运行测试，未做局内实测。
