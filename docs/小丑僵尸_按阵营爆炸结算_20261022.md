# 小丑僵尸：按阵营结算爆炸

## 改后规则

| 爆炸时的小丑阵营 | 作用对象 | 结算方式 |
| --- | --- | --- |
| 未魅惑、敌方 | 范围内植物及魅惑僵尸 | 直接调用正常清除入口，不走数值伤害，不受读报第二生命抗性减免 |
| 未魅惑、敌方 | 范围内罐子 | 保留原开罐逻辑 |
| 已魅惑、友方 | 范围内未魅惑的敌方僵尸 | **1800基础Penetration穿透爆炸伤害**，不强制清除 |
| 已魅惑、友方 | 植物、其他魅惑僵尸、罐子 | 不处理，不误伤友方或沿用敌方开罐行为 |

来源阵营在爆炸开始时读取。因此自然生成、撑杆落地生成、魅惑菇临时卡放置以及大喷菇等来源转换的小丑均使用同一套规则。撑杆若已魅惑，所释放小丑继续继承魅惑，开盒爆炸时走1800伤害分支。

## 范围与伤害细节

- 保留原 **250×200像素矩形**，区域中心相对小丑根(0,-45)，不扩大空间范围。
- 普通角色保留所在行及上下各一行限制。友方爆炸保留状态63筛选（正常、跳跃、水下、空中、地下、跳入泳池），目标仍需受击区域可监测且与范围相交。
- 敌方掩码改为2082=植物2＋魅惑僵尸32＋道具2048；友方结算即时改用20=敌方僵尸4＋攻击辅助框16。
- 复用普通爆炸的即时形状查询，避免刚生成或刚魅惑后，旧物理帧的重叠缓存导致漏判。分页查询不设置总目标数量上限。
- 按角色去重，同一目标的普通框与攻击辅助框只结算一次；结算前再次检查存活、阵营及有效性，跳过已被前一个死亡回调释放的目标。
- 友方对普通僵尸使用 `be_bomb(1800, is_cherry_bomb)`，沿用普通爆炸的防具及来源分类。当前继承的 `is_cherry_bomb=true`，因此按灰烬来源参与读报第二生命抗性；不是碾压或强制清除。
- 友方爆炸沿用寒冰1.5倍正伤害规则，1800为基础值；目标防具和相应抗性仍可能使其存活。读报第一生命耗尽仍先进入破报，致死溢出不传给第二生命。
- 僵王在有效受击区域与空间范围重叠、窗口开启时走1800穿透伤害接口，不套用普通僵尸强制删除；僵王跨行沿用共用爆炸的空间筛选语义。

## 保持不变

早爆概率5%、早爆4.4～7.45动作秒、晚爆13.22～22.68动作秒、速度倍率联动及撑杆释放小丑立即开盒等原设置不变。小丑自身开盒、爆炸特效、死亡和磁力禁爆流程沿用原链路。

不改变可选卡、解锁、场地、阳光节奏、自然波次刷新、选行或胜负条件。
