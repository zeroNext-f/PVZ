# 胆小菇：无攻击动画与轮末剧毒

- 300阳光、900本体生命、7.5秒卡片冷却保持。
- 攻击不再请求或播放射击OneShot，场景动画输出只连接原状态树，因此保留待机、缩头、恢复和休眠动作。旧射击资源保留文件，已从当前场景攻击库和输出链移除。
- 专用组件继承忧郁菇周身攻击，直接按动作时间推进四次脉冲：0.666667、1、1.34211、1.66667秒。保持2秒调度、每次20穿透伤害、238×204矩形、原忧郁菇四组粒子及个体倍率。忧郁菇自身仍使用原动画驱动，不受此修改影响。
- 每轮以第四次脉冲完成为结束点，对自身及八个邻格内的存活敌方普通僵尸各处理一次：未中毒者施加现有**3%本体最大生命/秒**剧毒；已中毒者立即追加结算一次剧毒伤害（本体最大生命3%，四舍五入且最低1点），不重置原跳伤计时。
- 九格按实际格子、僵尸逻辑行及根节点X定位，边缘仅取存在格子；不是攻击矩形或害怕胶囊。普通脉冲的状态1限制不用于九格施毒；魅惑友方不施毒。
- 剧毒沿用小喷菇接口：首次一秒后跳伤，不耗防具，不随个体动作减速或冻结暂停；状态仍不可叠加、不刷新。仅胆小菇轮末为已中毒目标额外结算一次；小喷菇和大喷菇重复施毒行为不变。追加伤害与定时跳伤共用入口，保留读报抗性和破报期间拒绝扣血规则。没有恢复5%高级毒、毒级升级或大喷菇高级毒扩散。
- 缩头不阻止周身攻击或轮末施毒；休眠、死亡及攻击组件禁用立即中断轮次，不补发剩余脉冲或轮末剧毒。已经开始的轮次即使失去范围内目标仍完成四次空范围查询和一次轮末九格查询，后续新轮需重新索敌。
- 逻辑时间服从个体速度因素，暂停及全局倍速沿用游戏树；无动画也不会变成固定现实秒输出。
