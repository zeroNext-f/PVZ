## 行走及屋顶斜坡

- 使用Ground位移，角色根节点反向抵消`_ground`轨道变化；不是固定使用MoveComponent的`ori_speed=20`。
- 行走动画原长4秒，地面轨道x从-79.8到44.3，一轮推进124.1像素。基准平均约31.025像素/秒，个体约27.9225～34.1275。步内速度按原曲线变化；这里未计动画循环切换帧开销。
- 宽屏场外共用逻辑：x≥800时额外2倍，每0.3秒检查，进入x<800后恢复1倍。寒冰、冻结、黄油及全局倍速继续叠乘。
- 开始砸击后共用攻击因素令移动停止。投掷没有新增独立移动锁，但其动作不推进地面位移，主要表现为停步投掷。
- 屋顶仍用同一Ground机制，按斜坡方向修正身体、受击/检测层的y位置。现行斜坡基础线段为(0,122)→(460,0)，场景组合后的横向范围约x=210～670；这不是巨人独有的上坡加减速。
- BodyCorrect偏移(-58,-130)。真实、普通检测和攻击检测受击框均为胶囊，半径30、高150、中心(0,-75)；攻击中的额外检测沿用横向-20修正。机制体型不由这些尺寸决定。

## 砸击

### 对象与范围

- 使用独立 AttackComponentZombieGargantuar，不使用普通僵尸100/秒啃食组件。
- 近距离检测仍继承50×5矩形，中心(-13,-40)，同行筛选。
- 可攻击植物状态掩码13=正常1+地刺4+低矮8，不含悬浮2；忽略梯子。先通过共用格内层级选中一个目标，再执行整格砸扁。
- 普通阵营检测植物和魅惑僵尸；被魅惑后切换为攻击敌对僵尸。
- 额外道具检测掩码3，包含罐子和“我是僵尸”脑子。

### 动作与结算

| 项目 | 当前设置 |
| --- | --- |
| 原砸击循环长度 | 2.66667秒 |
| 动作0秒 | `anim_start()`捕获当前目标/罐子/脑子引用 |
| 动作1.75秒 | `attack_once()`结算一次砸击并播放gargantuar_thump |
| 无其他速度因素的实际落锤时间 | 约1.591～1.944秒，即1.75/r |
| 无其他速度因素的实际一轮时长 | 约2.424～2.963秒，即2.66667/r |
| 行走进入砸击 | 配置0.2秒动画交叉过渡；因此落锤关键帧时间不能简单当作检测到目标后的绝对秒表读数 |
| 对植物 | 调用目标格`be_gargantuar_attack()`；逐个砸该格内有效且受击组件启用的植物，包括保护层、普通植物、花盆等 |
| 对僵尸 | 固定1800点Penetration穿透伤害，继续走目标自己的防具、寒冰易伤、抗性及死亡规则 |
| 对罐子/脑子 | 罐子走巨人开罐入口，脑子直接压扁，不是每次25点普通啃食 |

对普通植物的砸扁是专用清除/死亡入口，**不能理解为对植物造成1800伤害**。高生命植物也没有仅靠生命值抗锤的通用保护；植物如果覆写被压扁方法则执行其例外。

`owner_update_speed()`为空，不会像普通啃食那样将伤害参数乘以动作速度。寒冰减速降低砸击动画推进和频率，不把一锤1800改成900；冻结/黄油的0倍率使动作与关键帧停滞。

命中时不会重新按攻击范围索敌，只检查缓存引用是否仍有效及巨人自身未死亡，再处理缓存对象当前所在格。目标已经释放时会落空；仅死亡但尚未释放的引用不等于代码已经显式排除。罐子、脑子在分支中优先于角色引用。这些是现有实现细节，本次未修正或重做。

### 砸击与植物交互

- 地刺：被砸时先调用巨人`be_caltrop()`，此方法为空，不能扎胎或反杀巨人；地刺本身仍被砸掉。
- 地刺王：每次被砸扣`int(450/9)=50`点，满450时可承受9次这类砸击；破损阈值300/150/0。巨人仍不受其被砸反制。其他伤害可提前降低其剩余抗锤次数。
- 地刺/地刺王主动攻击的20点Real伤害仍可伤害巨人，不能把“被砸反制无效”理解为巨人免疫其所有伤害。
- 砸击不经过`be_zombie_eat`和`be_zombie_eat_once`，因此不触发只绑定啃食的效果：砸死小喷菇不会得到它的啃食亡语剧毒，砸死魅惑菇不会因啃食回调被魅惑，砸大蒜也不会走啃食换行回调。

## 投掷小鬼

### 触发和次数

- 接收本体生命损失信号后检查：`not is_throw_once && global_position.x>400 && curr_hp<=1500`。
- 一次触发立即将`is_throw_once=true`、`is_throw=true`；每只巨人最多投一次，不存在重复投掷冷却、补充小鬼或二次召唤。
- x=400不满足条件。低血量但x≤400时不触发；之后如果又满足条件并产生本体损血信号，仍可触发。不是单独进入范围就自动检查，也不要求本次伤害正好跨过1500。
- 行走进入投掷配置0.2秒交叉过渡。正在砸击时，砸击→投掷配置为动画结束切换，不能把“血量条件成立”当作立刻已经释放小鬼。
- 投掷原动作长2.75秒；在动作2.16667秒调用`throw_out_imp()`，隐藏本体与灰烬身体上的小鬼节点并清除`is_throw`，仍存活才正式创建25号小鬼。
- 基准随机倍率下，从投掷动画开始至释放约1.970～2.407秒；整段动作约2.5～3.056秒。冻结、黄油等继续影响动画时间。
- 释放时不重新检查x>400和1500阈值；触发后移动到门槛外也不自动撤销。死亡时不创建小鬼，但已经创建的小鬼不会随巨人死亡自动消失。

### 落点公式

`目标x = clamp(巨人当前全局x - 350, 200, 360) + randf_range(-50,50)`

| 参数 | 当前值 |
| --- | --- |
| 触发位置门槛MinXThrowGargantuar | 400，比较为严格大于 |
| XThrow | 350 |
| RangeXImpThrow | (200,360) |
| RangeRandomXThrow | (-50,50) |
| 总体最终落点x范围 | 150～410；先夹取再加随机，最终结果未再次夹取 |
| 目标y | 同行出生标记的全局y；屋顶另由小鬼身体位置补偿斜坡 |
| 是否换行 | 否，沿巨人当前lane生成 |

随机±50作用在水平x，不是注释文字所说的上下高度。公式固定x-350，不因巨人被魅惑反向而改成x+350。

### 被投小鬼

- 生成正式Z025Imp实例，先将根节点放在落点；通过巨人背上小鬼头部的全局位置计算初始BodyCorrect偏移，再用**1.5游戏秒**补间回小鬼的正常身体位置，表现飞行落地。
- 这1.5秒使用Tween，不随巨人的个体随机动作倍率缩放。期间关闭小鬼自主移动、攻击并隐藏影子，结束后恢复；不是把角色根节点本身沿抛物线移动。脚本也没有将其受击状态改成空中或跳跃。
- 小鬼通常继承共用本体270、179/89分段；本体场景基础动画倍率1.5，啃食子树另有2倍。这里仅列与巨人派生有关的参数，不将它等同于巨人本体属性。
- 请求携带母体行号、迷你/罐子标记和自然刷新参与标记；生成工厂还会以当前关卡覆盖迷你和我是僵尸标记。罐子标记会让小鬼在自己的初始化中另走半血处理。
- 没有传CurrWave，沿默认-1；继承自然刷新参与来源，博士来源不会因派生小鬼重新进入自然刷新集合。不消耗本波自然随机抽怪名额。
- 没有自动继承巨人的魅惑、冰冻、黄油、剧毒状态；魅惑巨人投出的小鬼仍按默认普通阵营初始化。

## 动画、死亡与其他共用项

| 原动作 | 长度 | 关键事件 |
| --- | --- | --- |
| idle | 1.75秒，循环 | 展示/待机 |
| walk | 4秒，循环 | 0秒标记行走开始 |
| smash | 2.66667秒，循环 | 0秒抓目标、1.75秒砸击 |
| throw | 2.75秒，循环资源 | 2.16667秒放小鬼；状态机正常在完成时退出，不表示会重复投掷 |
| death | 4.83333秒 | 0秒播放gargantudeath，末尾触发1游戏秒淡出删除 |

动作长度除以当前动作倍率才是实际推进时间；死亡动画同样受残留冰控/随机速度因素影响，淡出Tween本身是1秒。没有砸击命中后的额外眩晕、入场冲刺、红眼二阶段或因为进入半血而增加砸击伤害的脚本。资源目录有红眼贴图不等于屋顶入口启用了红眼巨人。

继承普通僵尸的血条、受击、阵营、清场统计、掉落等组件。掉落脚本默认：有效x范围0～900、币掉落概率0.3、银/金/钻条件比例0.5/0.4/0.1、花园植物概率0.004；但基础僵尸场景将若干字段序列化为null，未运行确认最终实例值，不能当作当前实测掉率。

迷你模式不属于本次屋顶正常配置的新增规则：若外部开启，会走共用半大小、半生命/分段、随机速度范围翻倍等逻辑；巨人投掷门槛仍是写死1500，并未按最大生命比例重算，因此不能将该门槛描述成所有模式永远“半血”。
