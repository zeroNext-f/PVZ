# 黑夜：魅惑菇收编卡与墓碑吞噬者费用调整

## 本次数值

| 项目 | 当前设置 |
| --- | --- |
| 墓碑吞噬者阳光费用 | 50，选卡与卡槽同读注册表 |
| 墓碑吞噬者冷却及行为 | 保持7.5秒及原吞碑机制 |
| 魅惑菇阳光费用/卡片冷却 | 100阳光/50秒，成功收编时结算一次；选卡及出战卡槽共读注册表 |
| 魅惑菇场地种植 | 禁止，手持卡只指向僵尸，不创建魅惑菇实例 |
| 原啃食魅惑回调 | 删除；既有/预置魅惑菇也不再通过啃食施加魅惑 |
| 收编产生的临时卡 | 对应被选中僵尸的种类，单次使用、免费、0冷却 |
| 临时卡总存在时间 | 30游戏秒：前25秒正常显示，最后5秒闪烁，然后释放 |

## 使用流程

1. 选择魅惑菇卡（包含模仿魅惑菇的卡），光标保留静态外观，不生成植物。
2. 鼠标指向已登记在战场的存活、未被魅惑的普通僵尸受击检测框时，目标使用独立颜色因素高亮。重叠时优先视觉靠前者；僵王使用独立角色/卡牌体系，不走此普通僵尸接口。
3. 左键重新查询光标下目标并复核费用、冷却。成功取得对应种类的临时卡后，清除原僵尸，不触发亡语；读报使用强制最终清除，不保留第二生命。扣魅惑菇卡费用并开始原冷却，播放MindControlled音效。
4. 临时僵尸卡出现在点击位置，费用为0，缩略图带魅惑色。此卡只保存僵尸种类，不保存原实例残血、防具损耗、异常状态或已使用技能阶段。
5. 选择临时卡后，在任意实际存在的场地格放置。跳过植物占位、格子普通僵尸禁种状态和水陆类型检查；已有植物不被移除，不需要花盆或睡莲。展示预览反向并使用魅惑色。
6. 通过正式僵尸创建入口生成该种类的新实例，使用默认生命、技能及特殊初始化；登记后立即调用其魅惑接口。新实例不参加自然出怪预算或提前刷新统计；保留现行僵尸自身机制。
7. 放置成功消费临时卡。失败不消费。柱子模式也只生成一个实例，不能把一张收编卡复制为多行僵尸。

铁门僵尸新增魅惑取消条件：任何来源的魅惑都会立即停止入场等待计时，并永久取消十倍追赶和1.25倍巡航，动画及移动恢复原基础节奏，保留个体随机、寒冰等其他倍率。因此收编卡放出的魅惑铁门也不会在一秒后启动加速。该修改不影响旗帜僵尸的入场机制。

## 期限及清理

- 期限从卡生成开始计算，总共30秒，不是30秒后再额外闪烁5秒。
- 25秒时启动既有卡片闪烁，30秒时销毁。到期时若仍手持此卡，先取消手持、删除预览，再正常移出临时卡列表并释放；一直手持不能续期。
- 右键取消手持不提前消耗临时卡，它仍按原期限留在场上。
- 取消魅惑菇选择、切换手持、结算或离开战斗时撤销目标高亮。目标死亡、被其他来源魅惑或移出鼠标后，下一次查询不再选中。
- 点击不合格对象不收编、不扣费、不开始冷却；同一次点击不会继续传给植物格按钮种下魅惑菇。
- 原僵尸清除及新僵尸魅惑分别沿用现有死亡/阵营登记流程，不改变波次刷新或胜利条件算法。
- 其他普通临时卡保留原“正常时长＋5秒闪烁、手持到期等待取消”的行为，仅本次收编卡严格到期。

## 代码位置

- `scripts/autoload/global/character_registry.gd`：墓碑吞噬者费用50。
- `scripts/manager/hand_manager/hypno_capture.gd`：点查询、高亮、收编与临时卡创建。
- `scripts/manager/hand_manager/hm_character.gd`：禁场地种菇、特殊卡任意格预览、单体生成及魅惑。
- `scripts/manager/hand_manager/hand_manager.gd`：直接点选僵尸、结束战斗取消手持。
- `scripts/ui/card/card.gd`：仅运行时的收编卡标记，不改变共享卡牌身份。
- `scripts/manager/card_manager.gd`：收编卡到期手持取消及销毁。
- `scripts/resources/plant_condition/condition_000_plant_base.gd`：拒绝魅惑菇的场地种植判定。
- `scripts/character/plant/plant_013_hypno_shroom.gd`：移除旧啃食魅惑逻辑。
- `scripts/character/components/body_character.gd`：独立悬停颜色因素，枚举在末尾追加。

不调整可选卡范围、植物或关卡解锁顺序、场地、阳光节奏、首波等待、波间刷新条件、出怪选行及胜负条件。角色和卡牌共用实现会在其他使用这些卡的模式中生效。

## 2026-10-24后续修改：手持到期规则

收编卡仍按25秒正常存在＋5秒闪烁计时，选中不会暂停倒计时。到期仍被手持时保留，直至右键取消（已到期则销毁）或成功左键放置（生成魅惑僵尸并消耗）。未手持仍到期销毁；未到期取消不重置剩余时间。本节覆盖上文“收编卡严格30秒到期强制取消手持”说明。
